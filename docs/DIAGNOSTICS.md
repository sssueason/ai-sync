# 诊断包与只读分诊（diagnostics）

> 解决的问题：**"看得到红、说不清为什么"** —— 一次性信号（打印前就被覆盖）、`log=0B` 这类误导数字、
> 托盘静默退出（应用日志无痕）。诊断包把**判定所依据的全部事实**落到一个可离线阅读的文件里。

## 诊断包（`tools/sync-ops-bundle.mjs`）
**条件命中**（满足任一条）时生成 `sync/reports/ops-bundle-<machine>-<时间戳>.md`：
- 文本卫生门禁 FAIL>0 · 迁移熔断 · 应用熔断或未生效 · 本轮 tick 有失败项

内容分 6 节：**0)** 固定映射的"先看这里"（不是推测）· **1)** `sync-status` 全文（判定所依据的每一条断言）·
**2)** 卫生/迁移/应用三项状态摘要与顶层明细 · **3)** 最近 tick 日志尾（含失败明细）·
**4)** 各仓 git 状态（**冲突判据用 `git ls-files -u`**，不看退出码）· **5)** 平台调度报告 · **6)** `--json` 结构化输出。

性质：**只读采集**（唯一写入物 = 报告本身）；**无条件不生成**；**同指纹不重复生成**（同一状况只留一份档案）；
人工排查用 `--force`。生成后 tick 会在日志行写 `诊断包：已生成 …（原因）`，`sync-status` 也有一条断言指路。

```bash
node tools/sync-ops-bundle.mjs --list        # 看当前条件
node tools/sync-ops-bundle.mjs --force --reason "人工排查"
```

## 只读分诊（`tools/sync-triage.mjs`，**默认关，一行可开**）
把诊断包的**事实摘要**（有界）交给一个**免费模型**，让它：
- 在**互斥枚举**里选一个问题类别（文本卫生 / git 分歧 / 调度漂移 / 引擎落后 / 迁移熔断 / 应用未生效 /
  镜像漂移 / 客户端噪音 / 未知）；
- 在**固定建议清单**里选一条建议 id；
- 输出严格 JSON `{class, remedy, confidence, human_reason}`。

**它不产生命令、不执行命令、没有写权限** —— 是建议器，不是执行者。不可用 / 超时 / 解析失败一律降级成
"没建议"，基线行为（诊断包）不变，**不影响 tick 的退出码**。

### 三条接口教训（踩过才写下来）
1. **调用原生可执行文件**：某些包管理器的 shim 是 `.cmd`，Node 直接 spawn 会被拒（EINVAL）；
   用包内的真实二进制（或用 `OPENCODE_BIN` 指定）。
2. **事实走附件、格式走指令**：整段提示词内联进命令行会被引号/竖线咬；而要求模型"复述某个 JSON 模板"
   会被它当成提示注入**拒绝**。正确做法是把事实写成附件、指令里只描述输出格式。
3. **跨进程交接文件别放系统临时目录**：有些机器上它返回的目录名字面带波浪号（`…\Local\TEMP_~1`），
   模型进程会把它规范化成另一个不存在的路径 ⇒ 附件读不到 ⇒ 表现为"模型没给出判定"，极易被误判成
   "模型波动"。**落在自己控制的目录**（用完即删），并把这类失败单独归类。

### 隐私提示（重要）
分诊会把**事实摘要发给模型服务**（诊断包的第 1–4 节：断言、状态、日志尾、git 状态）。
里面可能含路径与机器名 ⇒ 若你不接受这一点，**保持关闭**（默认就是关的）；诊断包本身始终只在本地。

### 怎么自评（换模型必须重跑）
准备一份金标集：每条给"事实摘要 + 可接受的类别"，逐条喂给分诊工具（`--input`），比较模型判定。
达标线建议：**输出 100% 可解析 + 类别命中 ≥ 90%**。注意：
- 同一模型同一金标集**会有波动**，多跑几轮看分布，不要只看一轮；
- **置信度不可作为可靠过滤器**（判错时它同样给 0.85+）；
- 真正可行动的是**建议 id**，类别允许"真歧义"时并列接受（例如某个事实同时含镜像与 git 线索）。
