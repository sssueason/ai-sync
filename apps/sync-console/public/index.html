逐项检查

每一行是一项自动检查：PASS 没问题 · WARN 提醒（不影响同步）· FAIL 要处理。出现 FAIL 时先看「实际」那列写的原因。

其他机器

每台机器同步完都会把自己的状态推上来，这里能看出谁掉队了（「几分钟前」太久没动 = 那台机器没在跑）。

需要你做的事

自动同步做不了、必须人工处理的（例如某个程序要重启才能读到新配置）。做完就会消失。

    这里决定「同步什么」和「多久同步一次」。改完点最下面的保存并应用即可，不需要命令行。 第一次装机按 ①②③④ 顺序走一遍就行。

    1. ① 同步空间（可选）

      如果你另外用百度网盘/OneDrive 这类客户端备份文档，这里填客户端的同步文件夹根目录（它自己在管的那个目录，不是子目录）；不打算用云盘镜像就留空，跳过这步。

      ⚠ 不要在这个目录里直接编辑文件：它由本机单向刷入，改动不会回流，还会被下次覆盖。

    2. ② 要同步哪些文件夹

      每一行是一个「集合」：来源 = 你本机上要同步的目录（权威版本在这里）；镜像里叫 = 它在同步空间里的子目录名。不填同步空间也可以只配 git 仓库（默认已经配好了）。

      一个来源目录只让一台机器写。两台机器写同一个镜像目录会冲突，保存时会被拦下。

      id来源（本机目录，可编辑）镜像里叫预估大小
      （「浏览…」会填到最近点选的那个框：同步空间根，或某一行的来源）
    3. ③ 多久同步一次

      同步间隔：每隔多少分钟自动跑一次（默认 5 分钟，改动很小可以调大）。状态上传间隔：多久把自己的状态推给其他机器看一次。

      镜像时间：每天几点把文档刷进同步空间（默认 22:00，避开你在用电脑的时段）。

      保存后系统里的定时任务会立刻按新间隔重排，不用手动改计划任务。

    4. ④ 保存并应用

      保存时会顺便检查定时任务是否与配置一致，不一致会自动重排（结果见上面那行提示）。

    「适配器」= 让哪些程序的配置跟着同步自动更新。每一项都可以单独关掉：关掉之后它的目标文件不再被同步系统改动（你已经手工调过的就保持原样）。
