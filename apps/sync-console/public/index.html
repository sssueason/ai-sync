    1. ① 同步空间（可选）

      网盘客户端的"同步文件夹"根目录。**不要**在这个目录里直接编辑文件（会被下次 seed 覆盖，且不回流权威源）。留空 = 只做 git 同步（µ1）。

    2. ② 同步空间 & 文件夹范围

      镜像（µ2）是**可选**的：留空/关掉就是纯 git 同步。填空时请选网盘客户端配的那个**同步文件夹根**（不是子目录）。 **属主模型**：每个 source 只由一台机器写；两个集合写同一个 target 必然冲突（会被拦下）。

      idsource（你的权威目录，机器本地可写）target（镜像内子目录）预估
      （「浏览…」会填到最近点选的那个输入框：同步空间根，或某个集合的 source）
    3. ③ 节拍与自启

      tick 间隔保存后**下一轮 tick 自动重排平台调度**（Windows 任务 / launchd plist），不需要命令行。

    4. ④ 保存并应用

    适配器（producers / owners）

    关掉某个 = 它的目标不再进入收敛。新增一个 agent = 加一个 adapters/owners/<id>.json。
